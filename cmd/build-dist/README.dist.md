# SessionTradeExecuter 配布版

現在はWeb版だけを配布します。[Web版の説明](README.md)を参照してください。

全5商品を一つの実行ファイルでOFF／DryRun／ONへ切り替え、ポート・上限枚数・時間帯ごとの手法を画面で設定します。日経の日中標準はNK225_D164_15、夜間はNK225_P164_06・静観・NK225_U165_03です。手法別の実ルールはconf/rules/の12個のTOMLです。ルールのsampleは作成しません。

初期設定は仮想売買・全商品OFFです。再配布は既存の実設定・実ルール・data・logを保持し、不足するルールだけ標準式から追加します。旧単品版の配布フォルダは新規生成しません。
