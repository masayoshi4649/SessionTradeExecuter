# D07の運転仕様

現在の標準は[新標準3手法](新標準手法.md)です。このページは引き続き選択できる旧手法の定義を説明します。

日経225ラージ・mini・microで昼夜とも選択できる手法です。TOPIXには適用しません。以下は変更せず残しているD07自体の仕様です。

入口の土台と、基本・追加・別入口の独立配分はTG04を引き継ぎます。上限10枚なら5・3・2枚です。担当間で空き枠を貸し借りしません。判断は日経225とTOPIXのラージ、約定と所有建玉は選択した商品を使います。

| 担当 | 日中 | 夜間 |
| --- | --- | --- |
| 基本 | 利益のある部分返済が実際に約定してから、残玉の利益の最高値を追跡。半分以下へ戻ったら残りを返済 | 利益を予算に残した1枚の追尾幅を、元の3Rと160ptの小さい方にする |
| 追加 | 1U進んだら利益玉を半分返済。押し戻りと再進行を確認して1枚ずつ取り直す | Uで利益追尾。黒字の全退出後は60秒以上待って再評価し、ドテンには40分方向の支持も要求 |
| 別入口 | TG04の長い残玉保持を維持 | TG04の長い残玉保持を維持 |

日中基本の利益追跡は、理由7・30・1435の部分返済が利益を伴って約定し、まだ残玉がある場合に開始します。その時の残玉平均建値を固定し、それ以降の最高利益を追います。返済依頼だけでは開始しません。保護条件で全返済した後、同じ親取引への追撃は止めます。

追加担当は初回損切り幅Rを維持し、利益の単位を`U=max(80pt, min(R, 1.5×入口時の公開ATR))`として固定します。ATRが使えなければRを使います。未確定の将来足を使ってUを書き換えません。

日中追加の部分返済は、保有枚数の半分を切り捨てた枚数です。残りは1.5U幅で追尾します。取り直しには、直前の利確位置から0.75Uの有利な押し戻り、そこから0.25Uの再進行、自己30秒・120秒方向の支持が15秒続くことが必要です。利確位置より不利な取り直しは拒否します。回転玉が1U進んだら返済し、次の条件を待ちます。損失予算と同時枚数上限も維持します。

夜間追加は1U順行後、0.75U幅で追尾します。黒字で全退出した後の60秒待機は全入口経路に適用します。元の入口が再成立する経路と、押し戻り・再進行で再参加する経路があります。損切り後の120秒、2連敗後の900秒停止は引き継ぎます。

ドテンは旧玉の返済後、5分差・120秒差が新方向、価格が公開20分平均の新方向側、自己30秒方向も15秒支持し、公開40分差も新方向の場合に行います。40分条件はドテン経路の追加確認であり、通常入口の全てに適用する条件ではありません。

元の損切り、米国現物開始前後の静観、場内強制返済は利益回転より優先します。幅やピークは判断条件であり、表示水準での約定を保証するものではありません。注文はcontrollerの生APIへ送り、実約定IDで所有分だけを管理します。

## 設定

Web版の商品オプションをOFF時に開き、日中の時間帯枠へ`NK225_D07`を選ぶと元のD07で運転できます。夜間のP05・静観・D07枠は維持します。以下は`conf/web-ui.toml`の該当商品の抜粋で、全5商品と他の時間帯枠も必要です。

```toml
[[instruments]]
# 発注する商品。
product = "NK225mini"
# OFFで設定を変更し、仮想はdryrun、実注文はliveへ画面から切り替えます。
mode = "off"
# 買い・売り各方向の同時保有上限。今回の運転の所有分だけを数えます。
max_per_side = 10
# 昼の手法。
day = "NK225_D07"
# 夜の手法。
night = "NK225_D07"

[[instruments.windows]]
id = "Day"
session = "Day"
start = "SESSION_START"
end = "SESSION_END"
method = "NK225_D07"
```

単品配布は廃止しています。画面の保存では移行版も保持するため、D07を明示選択した後の再起動でS01へ戻しません。手法IDを省略した旧設定の互換既定値は変更しません。

上限が10枚以外の場合は固定比率を整数配分します。少枚数では部分返済ができない、又は担当が0枚になるため、研究結果の単純な枚数倍にはなりません。

## 研究と実運用の区別

D07の判断用利益予算と連敗判定は手数料前で計算します。実際の手数料は消さず、約定ログとWebの確定損益では控除します。TG04・PG04の従来の判断費用条件は維持します。

研究はラージ気配を使う仮想約定です。実運用では商品の気配差、通信時間、部分約定、取消照合により価格と売買経路が変わります。再ONは新規運転として履歴で指標だけを準備するため、直後に新規条件が成立するとは限りません。

条件式は `conf/rules/NK225_D07.toml`、状態遷移は `internal/strategy` に実装しています。確認手順は[検証方法](検証結果.md)を参照してください。
