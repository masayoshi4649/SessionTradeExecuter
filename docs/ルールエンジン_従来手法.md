# T06・T04・U06の外部条件

日経T06、TOPIX T06、TOPIX夜T04、日経夜U06には、それぞれ独立したルールファイルを使う。ファイル名と `profile` は順に `NK225_T06`、`TOPIX_T06`、`TOPIX_T04`、`NK225_U06`。ファイル名の拡張子は `.toml`。起動時に選択した昼夜手法に対応する条件だけを注文器へ接続する。

| 対象 | 外部化した主な条件 |
| --- | --- |
| T06の入口 | 二つの方向判定の一致、発注気配の品質、両市場30秒支持、追跡極値からの反発幅、暖機・再準備待機 |
| T06の継続 | ATR縮小に合わせた損失予算、約定後の二市場固定アンカーからの逆行と持続秒数 |
| T06の出口 | 通常・早期出口影の損切り倍率、追尾開始、追尾幅、部分利確幅、最大保有時間 |
| T04の入口 | 過去帯の突破と方向一致、準備後の進行、30秒・120秒支持、気配品質 |
| U06の入口 | 過去帯突破、進行→押し戻り→再反発、二市場支持、両市場120秒逆流時の取消 |
| T04・U06の出口 | 追尾開始、追尾下限、停止判定、固定突破境界と相手方向の破綻 |
| 未参加補完枠 | 方向票、ATR・過去帯幅・呼値に基づくリスク幅、気配差、追尾による返済 |

T06は各21条件、夜間は各18条件。共通名の式でも、各ファイルは独立して編集できる。`threshold`、`entry_atr`、`width` などの入力は、その手法が元々使っていた設定値。標準式はそれらを使い、日経とTOPIXの差を維持する。

例えばT06の追跡新規の反発幅を0.5ATRに変更する場合は、当該ファイルの式を変更する。

```toml
"shadow.entry_distance" = "0.5 * atr"
```

夜間の最高利益から0.5Rの戻りで追尾する場合は次の式になる。最高利益が追尾開始条件に達するまでは適用されない。

```toml
"trail.floor" = "peak - 0.5 * risk"
```

数量上限、建玉ID、約定の照合、未来の板や足の排除、気配の正常性、場末返済はGo側に残す。新規方向は−1・0・1だけを採用し、小数を整数に切り捨てない。既存トレールを緩める変更や、同じ観測内でU06の複数確認段階を飛ばす動作は認めない。

T06の影が作った条件は次の観測で執行する。外部式にしても、判断した行の価格で都合よく約定させる動作へ変更しない。式の異常はE01影と実玉管理で共有され、注文を送る前に停止する。

D07・TG04・PG04が内部で使う従来手法の影は、従来プロファイルの標準条件を使う。単独T06・T04・U06用ファイルを編集しても、別手法の内部影へ暗黙には適用しない。D07等を変更する場合は対応する専用ファイルを使用する。

外部条件の変更は標準手法と別の戦略変更になる。標準の検証成績を、変更後の成績として扱わない。
