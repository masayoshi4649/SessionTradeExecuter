# P05：日経の米国開始前

現在の標準は[新標準3手法](新標準手法.md)です。このページは引き続き選択できる旧手法の定義を説明します。

| 時間帯 | 旧標準の時間割 |
| --- | --- |
| 日中 | [S01](S01.md) |
| 夜間開始〜米国開始15分前 | P05 |
| 米国開始15分前〜15分後 | 所有玉を返済・照合して静観 |
| 米国開始15分後〜夜間終了 | D07を新しい売買状態で開始 |

TOPIXは従来のT06／T04です。米国の夏時間は自動反映します。標準の米国開始が冬23:30・夏22:30なら、P05の終了は冬23:15・夏22:15です。境界の返済・照合が完了するまで後半の新規を待ちます。立会終了10分前の返済も優先します。

## 売買

1. 米国開始前の入口を緩めたB04を、実玉とは独立した仮想状態で動かします。その新規通知を受けて実際の新規を行います。
2. 実約定ごとに建値と最高利益を追跡します。利益が40pt以上になった玉は、最高利益から10pt戻り、判断時点でまだ利益があれば返済します。監視ラージの返済側気配（買い玉は買気配、売り玉は売気配）と実建値で評価し、発注は選択したmini・micro等へ行います。
3. 実玉の価格損切りは設けません。残った玉も、米国開始15分前には損益を問わず返済します。

B04内部の元の損切り・返済・再参加は、次の入口を作るために維持します。実玉から損切りを消したD07だけでは同じP05になりません。実玉の利確直後に自動で買い直す仕様でもありません。

主担当の入口は、効率しきい値0.35→0.25、押戻りの許容0.25→0.40R、戻り確認0.25→0.125R、米国後までの開始待ちの解除が主な差です。指標準備や方向条件は必要なので、17時に必ず新規するわけではありません。

## 数量・途中起動

Qtyは片方向上限です。10枚なら基本担当5・追加3・別入口2を基準に配分します。保有と未約定新規を合算して買い10枚・売り10枚を超えないようにします。反対玉の新規は可能ですが、反対玉だけで損失を相殺できる保証はありません。

部分約定も建値と利益を別々に管理し、当運転が所有する建玉IDだけを返済します。途中起動では過去の仮想売買を復元せず、履歴で指標を準備してから仮想B04と実玉の監視を始めます。

## 設定・更新

外部式は`conf/rules/NK225_P05.toml`です。夜間開始〜米国開始15分前の時間帯枠で使用します。全夜の`night`へ直接指定する設定は拒否します。変更は商品OFF時に行います。

旧標準の暗黙D07夜間や2枠は、標準式と照合して旧4枠へ正規化し、対象の設定だけ現在の3手法へ進めます。独自境界・改変式・数量・モード・接続先は保持します。現在の移行条件は[新標準手法](新標準手法.md)を参照してください。

更新では実行ファイルと、不足している`conf/rules/NK225_P05.toml`・`NK225_S01.toml`を配置してください。既存設定・既存ルール本文・台帳・ログは保持します。

## 検証範囲

DryRunは発注商品の新鮮な気配、実取引は確認済みの約定を使います。途中起動・約定遅延・部分約定で結果は変わります。利益条件成立後も、急変時の返済価格は保証されません。

P05の利益追尾を、両建ての成功や全夜の損切り廃止の保証とは扱いません。米国開始後のD07には従来の損切りがあります。
