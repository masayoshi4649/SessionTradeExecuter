# 時間帯ごとの手法

商品オプションで日中・夜間をさらに分けて手法を選べます。日経3商品の標準は日中`NK225_D164_15`、米国開始15分前まで`NK225_P164_06`、前後15分の静観、開始15分後から`NK225_U165_03`です。TOPIXは日中T06・夜間T04を維持します。 [新標準手法](新標準手法.md)。枠の間は静観します。

商品をOFFにし、注文の取消・照合が完了してから編集してください。Qtyは時間帯全体で共通の片方向上限です。枠の数だけ上限枚数が増えることはありません。

## 時計

通常の時刻は日本時間です。夜間の00:00〜11:59は翌日として解釈し、実際の立会範囲外なら運転を開始しません。「米国開始の15分前」などは米国夏時間へ自動追従します。開始を含み、終了は含みません。同時に有効になる枠は保存できません。

| 設定表記 | 意味 |
| --- | --- |
| `09:00` / `00:30` | 日本時間。夜間の午前時計は翌日。 |
| `SESSION_START` | controllerが示す立会開始。 |
| `SESSION_END` | controllerが示す立会終了。既存の終了前返済時刻は別途優先。 |
| `US_OPEN` | その日の米国開始。 |
| `US_OPEN-00:15` / `US_OPEN+00:15` | 米国開始の15分前 / 15分後。 |

## 切替時の建玉

時刻になると旧枠の新規を止め、当運転の未約定新規を取消・照合し、当運転の所有建玉を返済します。建玉と未確定注文がゼロになってから次の枠を開始します。返済や照合が遅れれば次の新規も待ちます。手動玉・前起動の玉には触れません。

時間帯の静観は商品OFFとは異なります。商品OFFは従来どおり、予約取消・照合後に既存玉を管理外へ外します。自動時間帯切替では所有玉を返済します。

DryRunの境界返済は、送信判断時点で鮮度確認済みの最新発注商品気配で仮想約定します。研究用バックテストの「判断の次の正常原行で約定」とは異なります。実注文の価格は上流の約定結果で確定します。端末時計が一度評価した時刻より前へ戻った場合は、その間の新規を止め、返済・照合は継続します。

市場指標の蓄積は継続します。新しい手法は新Portfolioとして始め、旧手法の玉、注文、利益予算、過去の仮想売買は引き継ぎません。従って、前半もD07の仮想売買を続けて後半へ影状態を渡す研究結果とは、そのまま同成績になりません。新手法の採用前に、この切替方式で全夜を検証する必要があります。

現行の共通指標器と異なる特徴係数を要求する手法の併用は起動検査で拒否します。研究特徴を必要とする枠が一つでもあれば、立会開始からその特徴も準備します。

## TOMLとREST

画面保存は`conf/web-ui.toml`へ反映します。旧標準のS01・P05・静観・D07の4枠と新旧の標準式が一致する日経商品だけを新3手法へ移行します。独自時間枠・数量・モード・接続先・改変式は保持します。移行版`settings_version=2`は通常保存で記録し、その後の明示的な旧手法選択を再移行しません。読込だけで元ファイルは書き換えません。 旧版の暗黙D07夜間と標準2枠は、標準式のときだけ旧標準4枠を経由します。単一外部式や独自係数は移行対象外です。

明示した `windows = []` は拒否します。全静観にしたい場合も、手法を「静観」にした枠を最低1つ残してください。設定を全削除した結果、旧昼夜手法が再開することを防ぎます。

```toml
[[instruments]]
product = "NK225mini"
mode = "off"
max_per_side = 10
day = "NK225_D164_15"
night = "NK225_U165_03"

[[instruments.windows]]
id = "day_all"
session = "Day"
start = "SESSION_START"
end = "SESSION_END"
method = "NK225_D164_15"

[[instruments.windows]]
id = "night_first"
session = "Night"
start = "SESSION_START"
end = "US_OPEN-00:15"
method = "NK225_P164_06"

[[instruments.windows]]
id = "night_quiet"
session = "Night"
start = "US_OPEN-00:15"
end = "US_OPEN+00:15"
method = ""

[[instruments.windows]]
id = "night_later"
session = "Night"
start = "US_OPEN+00:15"
end = "SESSION_END"
method = "NK225_U165_03"
```

これは日経の標準時間帯です。明示的に静観する枠は`method = ""`とします。D164_15は日中専用です。P164_06は米国開始15分前まで、U165_03は15分後からのNight枠専用です。枠なしの全夜指定は拒否します。旧P05も前半専用を維持します。全5商品の設定は維持してください。

`GET /api/settings` と `PUT /api/products/{product}/settings` の `windows` は同じ `id/session/start/end/method` 配列です。保存版 `revision` と `max_per_side` も指定します。既存の明示時間帯を、時間帯未対応の古い画面から消す更新は拒否します。稼働中の変更はRESTでも拒否します。

画面の現在手法・時間帯終了時刻・切替待ち表示は実際のworker状態です。実行ログにも枠切替と対象手法が残ります。
