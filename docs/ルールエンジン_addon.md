# D07追加担当の外部ルール

D07の追加担当は、デイV05・ナイトV16です。判断条件をExprの式へ切り出し、注文順序と既定値は移植前のまま維持しています。式は全件を起動時に読み込み、未定義・不足・型違いをエラーにします。実行中のファイル書換えは反映せず、再起動後に適用します。

## 入口・継続・出口

| 区分 | ルール識別子 | 既定の意味 |
| --- | --- | --- |
| 通常入口 | `addon.entry.*` | 40分方向効率で突破型・往復型を選び、押し戻りと二市場支持を30秒確認する |
| 利益単位 | `addon.exit_unit` | 初回のR・公開済みATRからUを固定する。`max(8×tick, min(R, 1.5×ATR))`、ATR欠測時はR |
| 追尾 | `addon.trail_active`、`addon.trail_width`、`addon.exit_trigger` | 1U進んだ後、昼1.5U・夜0.75U戻りで返済。停止幅は緩めない |
| 逆行監視 | `addon.adverse`、`addon.adverse_confirm`、`addon.opposite`、`addon.support` | 夜は短期逆行が15秒続いた後、5分・20分・40分の二市場支持を確認し、全返済又は半減 |
| 昼の部分利確 | `addon.partial_profit` | 1U到達時に利益のある玉から半分返済。以後は回転玉1枚を対象 |
| 利確後の戻り | `addon.pullback`、`addon.rebound`、`addon.self_support` | 0.75U押し戻り、0.25U反発、自銘柄の30秒・120秒支持を確認 |
| 昼の回転追加 | `addon.rotation_ready` | 上の状態が15秒継続し、元の損失予算内で、前回利確より不利でない価格に1枚追加 |
| 通常追撃 | `addon.add_trigger`、`addon.add_ready` | 部分利確前に二市場支持・進行幅・30秒経過・損失予算を確認 |
| 夜のドテン | `addon.flip_direction`、`addon.reentry_ready` | 逆向きの5分・120秒・30秒・40分変化と20分平均の位置を15秒確認 |
| 全返済後の待機 | `addon.cooldown` | 夜の利益返済60秒、連敗2回以上900秒、それ以外120秒 |

各式の入力型と説明は `internal/rules/addon_specs.go` が正本です。説明付きTOMLもこの定義から生成します。`own30` など方向を表す入力は、原則として検討方向を掛けた値です。プラスは検討方向への進行を意味し、未来の価格・最終収支を渡しません。

## 実行側に残す処理

式は条件を返すだけで、状態や注文を直接書き換えません。建玉の所有ID、最大枚数、時系列、次の正常板での仮想約定、情報欠測、状態の段階更新、場末返済、米国開始前後の静観はGo側に残します。返済・部分利確・回転追加・通常追撃・夜の再参加・通常入口の判定順も変えません。

`ResearchActive.Rules` は実行器の参照で、状態JSONには保存しません。`D07Rules` が有効なD07の入口だけに外部式を適用します。TG04・PG04の旧入口は従来条件を使います。`ResearchActive145` は同じ実行器を共有します。

式は数値・真偽値、比較・論理演算、三項式、`min`・`max`・`abs`を利用できます。外部通信、ファイル読書き、注文発行はできません。式の変更は売買成績を変えます。既定式で確認した結果を、変更後の結果として流用しません。
